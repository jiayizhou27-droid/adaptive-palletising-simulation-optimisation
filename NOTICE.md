# Third-party provenance

This repository extends the MathWorks `Palletize Boxes Using a Cobot` example. Helper files that retain a MathWorks copyright notice remain attributed to The MathWorks, Inc.

Before redistribution, users should review the licensing terms associated with their MATLAB installation, MathWorks examples, third-party robot and gripper models, and any included 3D assets.

The project author contributions include mixed-case layout planning, finite-buffer execution scheduling, seeded optimisation experiments, trajectory integration, validation utilities, result generation, and supervisory fault-verification work.
